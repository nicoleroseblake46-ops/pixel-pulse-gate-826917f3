# Neon Nexus

Create a modern, stylish web application with a gaming-inspired UI/UX. The platform must require users to sign up or log in before accessing any content.

🎮 Design Style:

Dark mode default (black / deep gray background)

Neon accents (purple, blue, or green glow)

Futuristic / gaming dashboard aesthetic (similar to esports or cyberpunk UI)

Smooth animations, hover effects, and glowing buttons

Use glassmorphism or soft blur panels

🔐 Authentication:

Full sign-up and login system

Email + password authentication

Optional: username display + avatar

After login, redirect to dashboard

🧭 Layout:

Main Dashboard (after login):

Top section: “Latest Updates” feed (cards with titles, timestamps, and short descriptions)

Center: dynamic content area

Left Sidebar (fixed):
Include exactly 5 sales

Cards

sokcs 

proxy

tools 

Sidebar should have icons + glowing hover effect

💰 Crypto Payments Only:

Create a Payments page that supports crypto-only transactions

Show supported coins (BTC, ETH, USDT)

Include:

Wallet address display

QR code for payments

Payment status (pending / confirmed)

Simulate or integrate crypto payment APIs if possible

⚙️ Features:

Real-time or simulated updates feed

Responsive design (mobile + desktop)

Smooth page transitions

Notifications or alerts for updates/payments

Clean component-based structure

🧠 Extra Enhancements:

Add a subtle animated background (particles or gradient motion)

Include a user profile section with stats or activity

Add a loading animation (gaming style)

🚀 Tech Preferences:

Use modern frameworks (React, Next.js, or similar)

Clean and maintainable code structure

Use reusable UI components

🎯 Goal:

The final product should feel like a premium gaming dashboard + crypto service platform, immersive and visually impressive, not a basic website.
